# User Stories

## Sprint 1

- [x] [[Mr. Tam the Elderly Patient]] => ask chatbot about symptoms via voice or text => get basic guidance without phone call
- [x] [[Dr. Hung the Specialist Physician]] => see treatment suggestions based on similar cases => make faster and more informed clinical decisions.
- [x] [[Mai the Busy Office Worker]] => book appointment online with shortest expected wait time => plan work schedule better.
- [x] [[Lan the Hospital Operations Manager]] => view statistics on the most frequently asked chatbot questions => improve service processes

## Sprint 2

- [x] [[Dr. Hung the Specialist Physician]] => be alerted early when number of booked appointments exceeds processing capacity => request additional staff support in time.
- [x] [[Mai the Busy Office Worker]] => want chatbot auto transfer to a live agent when question too complex => don't get stuck in an automated response loop.
- [x] [[Ms. Huong the Middle-Aged Patient]] => wearable device automatically sync vital signs to the hospital's system => no need to manually record and report health data.
- [x] [[Lan the Hospital Operations Manager]] => view weekly/monthly patient volume forecast reports => allocate staff and examination rooms appropriately in advance.

## Sprint 3

- [x] [[Mai the Busy Office Worker]] => receive suggested health check-up packages tailored to medical history => choose the most relevant service.
- [x] [[Mr. Tam the Elderly Patient]] => receive reminders for visits or medication based on condition => not miss important treatment schedules.
- [x] [[Dr. Hung the Specialist Physician]] => receive an auto alert when a patient's vital signs indicate abnormal risk => intervene before the condition becomes emergency.
- [x] [[Ms. Huong the Middle-Aged Patient]] => view simple trend chart of her health indicators over time on phone => understand health progress without needing doctor.
